# Telegram Alarm Bot — Required Packages
#
# This bot is built in Python and depends on three external libraries:
#
# python-telegram-bot
#   Handles all communication with Telegram. It connects to the Telegram API,
#   receives commands from users, and sends alarm messages back to the chat.
#
# APScheduler
#   The scheduling engine behind the bot. It manages all active alarms and
#   triggers them at exactly the right time — whether it's a one-time alarm,
#   a daily reminder, or a recurring interval.
#
# pytz
#   Provides accurate timezone data for every region in the world. This allows
#   the bot to schedule alarms in the user's local time rather than server time.
